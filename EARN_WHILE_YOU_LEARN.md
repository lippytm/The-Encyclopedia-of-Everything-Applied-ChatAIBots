The Earn-while-you-Learn curriculum is powered by the AI Conglomerate Swarms System (ACSS). Each level corresponds to a tier of the 300-book series.

- Bash scripting basics
- Package installation
- Processes, networking, Git, text tools, systemd
- **Credentials earned:** `CLL-L0` and `CLL-L1` tier, `CCSLL-L0-B008-GitPilot`

*"I can build a real developer environment"*
- Environment variables and `.env` security
- Docker and docker-compose

- Neovim / OMARCHY editor standard
- Pipes, redirects, log analysis
- Arch Linux / OMARCHY bootstrap
- System logging and monitoring
- Server hardening (ufw, fail2ban, SSH)
- Disk management and monitoring
- **Credentials earned:** `CLL-L1`, `CSEL-L0`, `CCSLL-L0`, `CLL-L2-B019-ServerGuardian`

### Level 2 — Builder (B-021–B-055: Python + Blockchain Basics)
*"I can write real software and deploy it"*
- Python from fundamentals to FastAPI

- **Credentials earned:** `CCSLL-L1/L2`, `CBSLL-L0/L1`

### Level 3 — Engineer (B-056–B-080: AI + DeFi)

- AI agents, RAG pipelines, fine-tuning
- DeFi protocols, AMMs, yield strategies
- Full-stack Web3 applications
- **Credentials earned:** `CCSLL-L3`, `CBSLL-L2/L3`

### Level 4 — Specialist (B-081–B-098: ACSS + Advanced Systems)
*"I can build and contribute to the ACSS"*
- Reinforcement learning trading bots
- ZK proofs and circuit design
- Autonomous AI systems
- Requires Charles review
- **Credentials earned:** `CCSLL-L4`, `CBSLL-L4`

### Level 5 — Master (B-099–B-100 + Contributions)

- Teach others — earn while they learn

## THE STUDENT JOURNEY (ACSS v2)

Every learner who enters the Earn-While-You-Learn ecosystem:

1. **Arrives** — onboarded via Slack (`/learn` command) or GESN platform
2. **Profiled** — Engine 2 classifies; Engine 3 builds a personalized curriculum plan backed by Fabric
3. **Learns** — ebook draft, lippytmai-narrated video tutorial, GESN sandbox mission
4. **Builds** — runs the build artifact: `lippytmai-launch <BOOK_ID>` or the ACVS sandbox
5. **Passes** — Build Gate verified; G13 approved; credential minted on Base
6. **Earns** — credential unlocks income streams: bounties, GESN node, affiliate
7. **Grows** — CRM Engine 8 evaluates upgrade eligibility; next curriculum level unlocked
8. **Becomes a teacher** — Level 5 learners write new encyclopedia content, earn teaching bounties
9. **Eventually** — helps prepare the Human Race to leave the planet
