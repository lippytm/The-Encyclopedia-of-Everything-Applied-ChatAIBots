### 10 Common Errors

1. **revert** — Transaction failed. Fix: Check require() conditions.
2. **out of gas** — Execution ran out of gas. Fix: Increase gas limit or optimize.
3. **nonce too low** — Transaction already processed. Fix: Increment nonce.
4. **invalid opcode** — Contract bug. Fix: Check for zero-address or overflow.
5. **execution reverted** — Explicit revert() called. Fix: Read the revert reason.
6. **insufficient funds** — Not enough ETH for gas. Fix: Fund the wallet.
7. **contract not deployed** — Wrong address. Fix: Verify contract address on explorer.
8. **ABI mismatch** — Wrong ABI for contract. Fix: Recompile and export fresh ABI.
9. **stack too deep** — Too many local variables. Fix: Use structs or split functions.
10. **reentrancy** — External call before state update. Fix: Use CEI pattern.

#!/usr/bin/env python3
"""mini_blockchain.py — BCL-L0-B056-BlockchainFoundation"""
import hashlib, json
from datetime import datetime

class Block:
    def __init__(self, index, data, prev_hash="0"):
        self.index = index
        self.timestamp = datetime.utcnow().isoformat()
        self.data = data
        self.prev_hash = prev_hash
        self.hash = self._hash()

    def _hash(self):
        content = json.dumps({"i":self.index,"t":self.timestamp,"d":self.data,"p":self.prev_hash})
        return hashlib.sha256(content.encode()).hexdigest()

class Blockchain:
    def __init__(self):
        self.chain = [Block(0, "Genesis Block")]

    def add(self, data):
        prev = self.chain[-1]
        self.chain.append(Block(len(self.chain), data, prev.hash))

    def is_valid(self):
        for i in range(1, len(self.chain)):
            if self.chain[i].prev_hash != self.chain[i-1].hash:
                return False
        return True

bc = Blockchain()
bc.add({"credential": "BCL-L0-B056-BlockchainFoundation", "earner": "lippytmai"})
print(f"Chain valid: {bc.is_valid()}")
print(f"Blocks: {len(bc.chain)}")
