### 10 Common Errors

1. **revert** — Transaction failed. Fix: Check require() conditions.
2. **out of gas** — Execution ran out of gas. Fix: Increase gas limit or optimize.
3. **nonce too low** — Transaction already processed. Fix: Increment nonce.
4. **invalid opcode** — Contract bug. Fix: Check for zero-address or overflow.
5. **execution reverted** — Explicit revert() called. Fix: Read the revert reason.
6. **insufficient funds** — Not enough ETH for gas. Fix: Fund the wallet.
7. **contract not deployed** — Wrong address. Fix: Verify contract address on explorer.
8. **ABI mismatch** — Wrong ABI for contract. Fix: Recompile and export fresh ABI.
9. **stack too deep** — Too many local variables. Fix: Use structs or split functions.
10. **reentrancy** — External call before state update. Fix: Use CEI pattern.

contract DIDRegistry {
    mapping(address=>string) public dids;
    mapping(address=>mapping(address=>uint256)) public delegates;

    function setDID(string calldata did) external {
        dids[msg.sender]=did;
