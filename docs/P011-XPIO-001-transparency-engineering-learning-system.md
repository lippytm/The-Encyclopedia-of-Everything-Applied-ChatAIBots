## Learning pathway

1. Files, hashes, and provenance
2. JSON work packets and schemas
3. Python artifact verification
4. SQLite data modeling and migrations
5. Logging and correlation IDs
6. Diagnostics and error taxonomies
7. Reproducible debugging and regression tests
8. API and connector boundaries
9. Clone identity, consent, and memory provenance
10. Blockchain provenance without false truth claims
11. Entrepreneurship through transparent product experiments
12. Quality Evidence Packets and human release decisions

Each unit uses Reality, Story, Quantum Questions, Demonstration, Build, Test, Business Application, Ethics, Proof of Learning, Mutation, Correction, and Archive modes.

Learning-to-Earning rewards verified approved work, not token ownership, and does not guarantee income, employment, funding, investment returns, or business success.

## Build Mode

Learners create a hash verifier, artifact register, SQLite migration, diagnostic rule, regression test, transparency event, and correction record using synthetic or public data.
