## Overview

The **HD Video Generator (HDVG)** is the ACSS multimedia production pipeline — it converts encyclopedia documents, ebook chapters, audiobook scripts, and GESN lesson plans into high-definition video content for advertising, marketing, and educational delivery.

Every video generated by HDVG is:
- **Source-verified** — generated from approved P011 quality-gated content only
- **Scene-structured** — built from JSON scene manifests that separate narration, code walkthroughs, animations, and interactive elements
- **ACSS-integrated** — connected to Hermes event bus, Fabric KB, and GESN interactive video platform
- **Multi-format** — exported as MP4 (H.264/H.265), WebM, and segmented HLS for streaming

*[Reality]* The pipeline architecture documented here is implementable with current AI video generation tools. *[Speculative]* Real-time personalized video rendering per learner is a forward-looking target for 2027+.

## 2. Scene Manifest Schema

The scene manifest is the central data structure of HDVG — a JSON document that describes every moment of a video:

```python
# acss/hdvg/scene_manifest.py
"""Scene manifest schema for the HD Video Generator."""

from __future__ import annotations
from dataclasses import dataclass, field
from typing import Literal, Any


SceneType = Literal[
    "intro",           # Title card + theme music + presenter intro
    "concept",         # Talking head or narrated animation explaining a concept
    "code_walkthrough",# Screen recording of code being written and explained
    "diagram",         # Animated architecture or data flow diagram
    "demo",            # Live demo of a running system
    "quiz",            # Interactive quiz embedded in video (GESN)
    "fable",           # Fable 5 animated story sequence [Fiction]
    "cta",             # Call to action (credential, next lesson, advertising)
    "outro",           # Summary + credential earned + next steps
]

VideoType = Literal[
    "educational",     # Ebook/lesson content
    "advertising",     # GESN advertising spot (B-099, B-100, I-097-100, A-093-100)
    "tutorial",        # Step-by-step build tutorial
    "explainer",       # 2-3 min concept explainer
    "lecture",         # Long-form educational lecture (15-60 min)
]


@dataclass
class NarrationLine:
    text: str
    ssml: str          # SSML-formatted for TTS (includes pauses, emphasis)
    speaker: str       # "lippytmai", "lippy_killjoy", "charles", "narrator"
    duration_sec: float


@dataclass
class VisualSpec:
    visual_type: Literal[
        "screen_record", "ai_generated", "diagram", "animation",
        "talking_head", "slides", "code_highlight"
    ]
    description: str   # For AI generation: detailed prompt
    duration_sec: float
    assets: list[str] = field(default_factory=list)  # Pre-existing asset paths
    overlay_text: str | None = None


@dataclass
class InteractiveElement:
    element_type: Literal["quiz", "code_challenge", "credential_gate", "cta_button"]
    timestamp_sec: float   # When in the video this element appears
    content: dict[str, Any]  # Quiz questions, challenge spec, etc.
    blocks_playback: bool = True   # Pause video until answered?
    credential_gate: bool = False  # Does completing this unlock a credential?


@dataclass
class Scene:
    scene_id: str
    scene_number: int
    scene_type: SceneType
    title: str
    narration: list[NarrationLine]
    visual: VisualSpec
    interactive: list[InteractiveElement] = field(default_factory=list)
    start_sec: float = 0.0
    duration_sec: float = 0.0
    source_doc: str | None = None   # Which encyclopedia doc this scene came from
    quality_verified: bool = False


@dataclass
class SceneManifest:
    manifest_id: str
    video_title: str
    video_type: VideoType
    ebook_ref: str | None    # e.g., "B-001" for Beginner book 1
    total_duration_sec: float
    scenes: list[Scene]
    target_resolution: str = "1920x1080"  # HD default
    target_fps: int = 30
    audio_format: str = "AAC-LC 48kHz stereo"
    export_formats: list[str] = field(default_factory=lambda: ["mp4", "webm", "hls"])
    gesn_interactive: bool = False  # True for GESN interactive video platform
    advertising_ref: str | None = None  # "GESN-B099", "GESN-I097", etc.
```

## 3. Scene Manifest Generator

```python
# acss/hdvg/manifest_generator.py
"""
Generates a complete scene manifest from a P011 encyclopedia document or ebook chapter.
Uses Claude 3.5 for narration scripts and GPT-4o for structured JSON output.
"""

from __future__ import annotations
import json
import uuid
from typing import Any
from .scene_manifest import SceneManifest, Scene, NarrationLine, VisualSpec


MANIFEST_SYSTEM_PROMPT = """You are the HDVG Scene Manifest Generator for lippytm.ai.

Convert the provided educational content into a complete JSON scene manifest.
Every scene must have:
- A clear scene_type from: intro, concept, code_walkthrough, diagram, demo, quiz, fable, cta, outro
- A narration array with text and SSML (include <break> tags for natural pauses)
- A visual spec describing exactly what appears on screen
- Duration estimates in seconds

For educational videos: concept scenes 60-120 sec, code walkthroughs 120-300 sec.
For advertising videos (GESN): max 90 seconds total, high energy, clear CTA.
For interactive GESN videos: include quiz elements at natural pause points.

Always end with an outro scene that includes credential information if applicable."""


class ManifestGenerator:
    """Converts encyclopedia content into HDVG scene manifests."""

    def __init__(self, amil_client: Any, fabric_client: Any) -> None:
        self.amil = amil_client
        self.fabric = fabric_client

    async def from_ebook_chapter(
        self,
        chapter_content: str,
        ebook_ref: str,
        video_type: str = "educational",
        gesn_interactive: bool = False,
        advertising_ref: str | None = None,
    ) -> SceneManifest:
        """Generate a scene manifest from an ebook chapter."""

        # Get existing scene patterns from Fabric for this ebook level
        level = "beginner" if ebook_ref.startswith("B-") else (
            "intermediate" if ebook_ref.startswith("I-") else "advanced"
        )
        patterns = await self.fabric.get_video_patterns(level=level)

        prompt = f"""Convert this educational content into a complete scene manifest JSON.

Content:
{chapter_content[:4000]}

Ebook reference: {ebook_ref}
Video type: {video_type}
Interactive GESN: {gesn_interactive}
Advertising ref: {advertising_ref or 'None'}
Level: {level}
Successful patterns from similar videos: {json.dumps(patterns[:3], indent=2)}

Return a JSON object with fields: video_title, total_duration_sec, scenes (array)"""

        raw = await self.amil.call_json(
            model="gpt-4o",
            system=MANIFEST_SYSTEM_PROMPT,
            prompt=prompt,
        )

        return self._assemble_manifest(raw, ebook_ref, video_type, gesn_interactive, advertising_ref)

    async def from_advertising_brief(
        self,
        program_name: str,
        key_messages: list[str],
        target_audience: str,
        gesn_ref: str,
        duration_sec: int = 90,
    ) -> SceneManifest:
        """Generate an advertising scene manifest for GESN promotion."""

        prompt = f"""Create a high-energy advertising video scene manifest.

Program: {program_name}
Key messages: {key_messages}
Target audience: {target_audience}
GESN reference: {gesn_ref}
Max duration: {duration_sec} seconds

Structure:
- Hook scene (0-5 sec): attention-grabbing visual + one-line hook
- Problem scene (5-20 sec): pain point the viewer has
- Solution scene (20-50 sec): how GESN solves it with demos
- Social proof (50-70 sec): credentials earned, learner outcomes
- CTA scene (70-{duration_sec} sec): "Start free at gesn.lippytm.ai"

Return complete JSON scene manifest."""

        raw = await self.amil.call_json(
            model="gpt-4o",
            system=MANIFEST_SYSTEM_PROMPT,
            prompt=prompt,
        )

        return self._assemble_manifest(
            raw,
            ebook_ref=gesn_ref,
            video_type="advertising",
            gesn_interactive=False,
            advertising_ref=gesn_ref,
        )

    def _assemble_manifest(
        self,
        raw: dict,
        ebook_ref: str | None,
        video_type: str,
        gesn_interactive: bool,
        advertising_ref: str | None,
    ) -> SceneManifest:
        scenes = []
        elapsed = 0.0
        for i, s in enumerate(raw.get("scenes", [])):
            narration = [
                NarrationLine(
                    text=n.get("text", ""),
                    ssml=n.get("ssml", f"<speak>{n.get('text', '')}</speak>"),
                    speaker=n.get("speaker", "lippytmai"),
                    duration_sec=n.get("duration_sec", 10.0),
                )
                for n in s.get("narration", [])
            ]
            visual = VisualSpec(
                visual_type=s.get("visual", {}).get("visual_type", "ai_generated"),
                description=s.get("visual", {}).get("description", ""),
                duration_sec=s.get("duration_sec", 30.0),
            )
            duration = s.get("duration_sec", 30.0)
            scene = Scene(
                scene_id=f"scene_{i:03d}_{uuid.uuid4().hex[:6]}",
                scene_number=i + 1,
                scene_type=s.get("scene_type", "concept"),
                title=s.get("title", f"Scene {i+1}"),
                narration=narration,
                visual=visual,
                start_sec=elapsed,
                duration_sec=duration,
                source_doc=ebook_ref,
            )
            elapsed += duration
            scenes.append(scene)

        return SceneManifest(
            manifest_id=f"manifest_{uuid.uuid4().hex[:12]}",
            video_title=raw.get("video_title", "Untitled"),
            video_type=video_type,  # type: ignore[arg-type]
            ebook_ref=ebook_ref,
            total_duration_sec=elapsed,
            scenes=scenes,
            gesn_interactive=gesn_interactive,
            advertising_ref=advertising_ref,
        )
```

## 4. Video Composer (FFmpeg Pipeline)

```bash
#!/usr/bin/env bash
# hdvg/compose_video.sh
# Assembles a video from scene assets using FFmpeg
# Called by the HDVG pipeline after all scene assets are generated

set -euo pipefail

MANIFEST_JSON="$1"
OUTPUT_DIR="$2"
VIDEO_ID=$(echo "$MANIFEST_JSON" | python3 -c "import json,sys; print(json.load(sys.stdin)['manifest_id'])")

echo "🎬 Composing video: $VIDEO_ID"

# Build FFmpeg concat file from scene asset paths
python3 - "$MANIFEST_JSON" "$OUTPUT_DIR" << 'EOF'
import json, sys, pathlib

manifest = json.load(open(sys.argv[1]))
output_dir = pathlib.Path(sys.argv[2])

with open(output_dir / "concat.txt", "w") as f:
    for scene in manifest["scenes"]:
        scene_file = output_dir / f"scene_{scene['scene_number']:03d}.mp4"
        if scene_file.exists():
            f.write(f"file '{scene_file}'\n")
        else:
            print(f"WARNING: missing scene asset {scene_file}")
EOF

# Concatenate all scenes into master video (H.264, AAC)
ffmpeg -y \
  -f concat -safe 0 -i "$OUTPUT_DIR/concat.txt" \
  -c:v libx264 -preset slow -crf 18 \
  -c:a aac -b:a 192k \
  -movflags +faststart \
  "$OUTPUT_DIR/${VIDEO_ID}_master.mp4"

# Generate WebM for browser compatibility
ffmpeg -y \
  -i "$OUTPUT_DIR/${VIDEO_ID}_master.mp4" \
  -c:v libvpx-vp9 -b:v 2M \
  -c:a libopus \
  "$OUTPUT_DIR/${VIDEO_ID}.webm"

# Generate HLS segments for streaming
ffmpeg -y \
  -i "$OUTPUT_DIR/${VIDEO_ID}_master.mp4" \
  -c copy \
  -hls_time 4 \
  -hls_playlist_type vod \
  -hls_segment_filename "$OUTPUT_DIR/hls/${VIDEO_ID}_%03d.ts" \
  "$OUTPUT_DIR/hls/${VIDEO_ID}.m3u8"

echo "✅ Video composed: $OUTPUT_DIR/${VIDEO_ID}_master.mp4"
echo "📡 HLS playlist: $OUTPUT_DIR/hls/${VIDEO_ID}.m3u8"
```

## 6. ACSS Integration Points

| HDVG Component | ACSS System | Integration |
|---|---|---|
| Scene manifest generation | AMIL (Claude + GPT-4o) | Model routing per scene type |
| Narration voice | lippytmai clone | ElevenLabs API with lippytmai voice profile |
| Content source | Engine 4 (Documentation) | All video content comes from quality-gated docs |
| Quality gate | Engine 5 (Quality Review) | Every video passes G1–G13 before publish |
| Interactive quizzes | GESN platform | Scene `InteractiveElement` served via GESN video player |
| Completion tracking | Fabric + CRM | Learner video completion events published to Hermes |
| Credential issuance | On-chain (Base ERC-721) | `credential_gate` scene elements trigger SkillBadge mint |
| CDN delivery | Hermes CDN events | Publish event triggers CDN cache push |
