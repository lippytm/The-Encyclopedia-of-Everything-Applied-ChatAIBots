### 10 Common Errors

1. **revert** — Transaction failed. Fix: Check require() conditions.
2. **out of gas** — Execution ran out of gas. Fix: Increase gas limit or optimize.
3. **nonce too low** — Transaction already processed. Fix: Increment nonce.
4. **invalid opcode** — Contract bug. Fix: Check for zero-address or overflow.
5. **execution reverted** — Explicit revert() called. Fix: Read the revert reason.
6. **insufficient funds** — Not enough ETH for gas. Fix: Fund the wallet.
7. **contract not deployed** — Wrong address. Fix: Verify contract address on explorer.
8. **ABI mismatch** — Wrong ABI for contract. Fix: Recompile and export fresh ABI.
9. **stack too deep** — Too many local variables. Fix: Use structs or split functions.
10. **reentrancy** — External call before state update. Fix: Use CEI pattern.

## Appendix H: Capstone Project — NFTs: Digital Ownership Explained

### Project: `CredentialNFT.sol`

**Credential gated:** `BCL-L0-B063-NFTCreator`

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "@openzeppelin/contracts/token/ERC721/ERC721.sol";
import "@openzeppelin/contracts/token/ERC721/extensions/ERC721URIStorage.sol";
import "@openzeppelin/contracts/access/Ownable.sol";

/// @title CredentialNFT — BCL-L0-B063-NFTCreator capstone
/// @notice Issues soulbound-style credential NFTs for book completion
contract CredentialNFT is ERC721URIStorage, Ownable {
    uint256 private _tokenIdCounter;

    event CredentialMinted(address indexed earner, uint256 tokenId, string bookId);

    constructor() ERC721("ACSS Credential", "ACRED") Ownable(msg.sender) {}

    function mintCredential(address earner, string calldata bookId, string calldata tokenURI_) external onlyOwner returns (uint256) {
        uint256 tokenId = ++_tokenIdCounter;
        _mint(earner, tokenId);
        _setTokenURI(tokenId, tokenURI_);
        emit CredentialMinted(earner, tokenId, bookId);
        return tokenId;
    }
}

```
