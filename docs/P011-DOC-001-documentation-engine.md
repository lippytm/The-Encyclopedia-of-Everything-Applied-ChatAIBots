# P-011-DOC-001 — Documentation Engine (Engine 4)
### *Autonomous Encyclopedia Generation: From Build Artifacts and Fabric Patterns to Published Knowledge*

> *"Documentation is not what you write after you build. Documentation is what makes the build reproducible, teachable, and correctable — by anyone, anywhere, including a robot arm that has never met you."*
> — Charles Earl Lipshay (lippytm.ai)

---

## Overview

**Engine 4 — Documentation** is the knowledge creation and maintenance core of the Prompt #11 system. It converts raw outputs — build artifacts, code commits, Fabric-detected patterns, Hermes events, CI results, and learner outcomes — into the structured encyclopedia documents that make up this repository.

Engine 4 is the engine that wrote much of this encyclopedia. Every time a pattern is proven, a build is completed, or a learner reaches a milestone, Engine 4 has the opportunity to update, extend, or create a document.

## 2. Encyclopedia Document Format (Enforced Standard)

All documents generated by Engine 4 **must** follow this structure exactly:

```markdown
# [Title]
### *[Subtitle — one sentence describing the document's unique value]*

> *"[Epigraph — a relevant quote attributed to Charles Earl Lipshay or a Fable 5 character]"*
> — [Attribution]

---

## Overview

[2–4 paragraph overview of the document's purpose, scope, and connection to ACSS]

---

## 1. [First Section]
## 2. [Second Section]
...
## N. [Last Section]

---

## Further Reading

- 📄 [`docs/related-doc.md`](related-doc.md) — one-sentence description
- 📄 [`docs/another-doc.md`](another-doc.md) — one-sentence description
- 🏠 [`README.md`](../README.md) — Encyclopedia home
```

**Enforcement rules:**
- Every document needs at least one Markdown table mapping concepts to implementations
- Code blocks must specify a language (`python`, `solidity`, `bash`, `yaml`, etc.)
- Truth labels required for speculative content: *[Reality]*, *[Speculative]*, *[Fiction]*
- Minimum 2 items in Further Reading; always include `README.md`
- Section numbers always start at `## 1.`

## 3. Documentation Engine Implementation

```python
# acss/p011/engines/documentation/doc_engine.py
"""
Prompt #11 Engine 4 — Documentation Engine.
Converts build artifacts, Fabric patterns, and Hermes events into encyclopedia documents.
"""

from __future__ import annotations
import re
import uuid
from dataclasses import dataclass
from datetime import datetime
from pathlib import Path
from typing import Any, Literal


DocTriggerType = Literal[
    "new_pattern",           # Fabric detected a new recurring pattern
    "build_completed",       # CI build + tests passed
    "pr_merged",             # PR merged to main
    "learner_milestone",     # Learner reached a credential gate
    "correction_required",   # Error found in existing doc
    "scheduled_refresh",     # Nightly doc freshness check
    "manual_request",        # Human (Charles) requests doc creation
]


@dataclass
class DocTrigger:
    trigger_id: str
    trigger_type: DocTriggerType
    source_event: dict[str, Any]
    target_doc_path: str | None  # None = create new doc
    priority: Literal["high", "normal", "low"] = "normal"
    triggered_at: datetime = None  # type: ignore[assignment]

    def __post_init__(self) -> None:
        if self.triggered_at is None:
            self.triggered_at = datetime.utcnow()


@dataclass
class GeneratedDoc:
    doc_path: str
    title: str
    content: str
    trigger_id: str
    action: Literal["create", "update", "cross_link"]
    sections: list[str]
    word_count: int
    code_blocks: int
    tables: int
    quality_gate_passed: bool = False
    pr_number: int | None = None


class DocumentationEngine:
    """
    Engine 4: Converts ACSS signals into encyclopedia documentation.

    Triggered by Hermes events; generates or updates Markdown docs
    following the strict encyclopedia format; creates PRs via ACD.
    """

    DOCS_DIR = Path("docs")
    MAX_SECTION_DEPTH = 3
    MIN_WORD_COUNT = 300
    MIN_TABLES = 1
    MIN_CODE_BLOCKS = 1

    # Claude 3.5 system prompt for doc generation
    DOC_SYSTEM_PROMPT = """You are lippytmai, the documentation engineer for the lippytm.ai encyclopedia.

Generate a complete encyclopedia document following this EXACT format:
1. Title (# heading) + subtitle (### *italics*)
2. Epigraph blockquote attributed to Charles Earl Lipshay (lippytm.ai)
3. Horizontal rule ---
4. ## Overview section (2-4 paragraphs)
5. Numbered ## sections (## 1. through ## N.)
6. ## Further Reading section at the end

Rules:
- Every section must have at least one Markdown table mapping concepts to implementations
- All code blocks must specify a language tag
- Use *[Reality]*, *[Speculative]*, or *[Fiction]* labels for uncertain content
- Write for a technical learner audience; no filler content
- Cross-link to existing docs where relevant (cite exact file paths)
- Minimum 300 words; typical 800-2000 words"""

    def __init__(
        self,
        amil_client: Any,
        fabric_client: Any,
        hermes_client: Any,
        repo_path: str,
    ) -> None:
        self.amil = amil_client
        self.fabric = fabric_client
        self.hermes = hermes_client
        self.repo_path = Path(repo_path)

    async def process_trigger(self, trigger: DocTrigger) -> GeneratedDoc | None:
        """Process a documentation trigger and generate/update a doc."""

        # 1. Decide: create, update, or cross-link?
        action = self._classify_action(trigger)

        # 2. Gather context from Fabric
        context = await self._gather_context(trigger)

        # 3. Generate content with Claude 3.5
        if action == "create":
            doc = await self._create_new_doc(trigger, context)
        elif action == "update":
            doc = await self._update_existing_doc(trigger, context)
        else:
            doc = await self._update_cross_links(trigger, context)

        if doc is None:
            return None

        # 4. Quality gate check
        doc.quality_gate_passed = self._run_format_gate(doc)

        if not doc.quality_gate_passed:
            await self.hermes.publish(
                "p11.doc.format_gate_failed",
                {"trigger_id": trigger.trigger_id, "doc_path": doc.doc_path},
            )
            return doc

        # 5. Write to disk (via PR workflow in production)
        doc_full_path = self.repo_path / doc.doc_path
        doc_full_path.write_text(doc.content, encoding="utf-8")

        # 6. Publish to Hermes
        await self.hermes.publish(
            "p11.doc.generated",
            {
                "trigger_id": trigger.trigger_id,
                "doc_path": doc.doc_path,
                "action": action,
                "word_count": doc.word_count,
            },
        )

        return doc

    def _classify_action(self, trigger: DocTrigger) -> Literal["create", "update", "cross_link"]:
        if trigger.target_doc_path is None:
            return "create"
        target = self.repo_path / trigger.target_doc_path
        if target.exists():
            return "update" if trigger.trigger_type in (
                "new_pattern", "correction_required", "scheduled_refresh"
            ) else "cross_link"
        return "create"

    async def _gather_context(self, trigger: DocTrigger) -> dict[str, Any]:
        """Collect relevant Fabric context for document generation."""
        kb_results = await self.fabric.search_curriculum_resources(
            domain=trigger.source_event.get("domain", "general"),
            target_level=trigger.source_event.get("level", 1),
            learner_type="human",
        )
        existing_docs = list(self.DOCS_DIR.glob("*.md")) if (
            self.repo_path / self.DOCS_DIR
        ).exists() else []
        return {
            "kb_results": kb_results[:5],
            "existing_doc_paths": [str(d.name) for d in existing_docs[:20]],
            "source_event": trigger.source_event,
        }

    async def _create_new_doc(
        self, trigger: DocTrigger, context: dict
    ) -> GeneratedDoc | None:
        doc_name = trigger.source_event.get(
            "doc_name", f"auto-{uuid.uuid4().hex[:8]}.md"
        )
        prompt = f"""Create a new encyclopedia document for:
Topic: {trigger.source_event.get('topic', 'Unknown')}
Trigger: {trigger.trigger_type}
Domain: {trigger.source_event.get('domain', 'general')}
Level: {trigger.source_event.get('level', 1)}

Existing docs for cross-linking: {', '.join(context['existing_doc_paths'][:10])}
KB context: {context['kb_results'][:3]}"""

        content = await self.amil.call(
            model="claude-3-5-sonnet-20241022",
            system=self.DOC_SYSTEM_PROMPT,
            prompt=prompt,
        )

        return self._build_generated_doc(
            doc_path=f"docs/{doc_name}",
            content=content,
            trigger_id=trigger.trigger_id,
            action="create",
        )

    async def _update_existing_doc(
        self, trigger: DocTrigger, context: dict
    ) -> GeneratedDoc | None:
        existing = (self.repo_path / trigger.target_doc_path).read_text(encoding="utf-8")
        prompt = f"""Update this existing encyclopedia document with new information.

Existing document:
{existing[:3000]}

New information to incorporate:
{trigger.source_event.get('new_content', '')}

Type of update: {trigger.trigger_type}
Instructions: Add a new section or update the relevant section. Do NOT change the overall format.
Return the COMPLETE updated document."""

        content = await self.amil.call(
            model="claude-3-5-sonnet-20241022",
            system=self.DOC_SYSTEM_PROMPT,
            prompt=prompt,
        )

        return self._build_generated_doc(
            doc_path=trigger.target_doc_path,
            content=content,
            trigger_id=trigger.trigger_id,
            action="update",
        )

    async def _update_cross_links(
        self, trigger: DocTrigger, context: dict
    ) -> GeneratedDoc | None:
        existing = (self.repo_path / trigger.target_doc_path).read_text(encoding="utf-8")
        new_link = trigger.source_event.get("new_link", "")
        new_link_desc = trigger.source_event.get("new_link_description", "")

        if "## Further Reading" in existing:
            updated = existing.replace(
                "- 🏠 [`README.md`](../README.md) — Encyclopedia home",
                f"- 📄 {new_link} — {new_link_desc}\n- 🏠 [`README.md`](../README.md) — Encyclopedia home",
            )
        else:
            updated = existing + f"\n\n## Further Reading\n\n- 📄 {new_link} — {new_link_desc}\n- 🏠 [`README.md`](../README.md) — Encyclopedia home\n"

        return self._build_generated_doc(
            doc_path=trigger.target_doc_path,
            content=updated,
            trigger_id=trigger.trigger_id,
            action="cross_link",
        )

    def _build_generated_doc(
        self,
        doc_path: str,
        content: str,
        trigger_id: str,
        action: Literal["create", "update", "cross_link"],
    ) -> GeneratedDoc:
        sections = re.findall(r"^## .+", content, re.MULTILINE)
        code_blocks = len(re.findall(r"^```\w+", content, re.MULTILINE))
        tables = len(re.findall(r"^\|.+\|$", content, re.MULTILINE))
        words = len(content.split())
        title_match = re.search(r"^# (.+)", content, re.MULTILINE)
        title = title_match.group(1) if title_match else "Untitled"

        return GeneratedDoc(
            doc_path=doc_path,
            title=title,
            content=content,
            trigger_id=trigger_id,
            action=action,
            sections=[s.strip("# ") for s in sections],
            word_count=words,
            code_blocks=code_blocks,
            tables=tables,
        )

    def _run_format_gate(self, doc: GeneratedDoc) -> bool:
        """Check the generated doc meets encyclopedia format requirements."""
        checks = [
            doc.word_count >= self.MIN_WORD_COUNT,
            doc.tables >= self.MIN_TABLES,
            doc.code_blocks >= self.MIN_CODE_BLOCKS,
            "## Further Reading" in doc.content,
            "## Overview" in doc.content,
            "README.md" in doc.content,
            bool(re.search(r"> \*.+\*", doc.content)),  # Has epigraph
        ]
        return all(checks)
```

## 4. Scheduled Documentation Refresh

Engine 4 runs a nightly scheduled job to check all existing docs for:

| Check | Threshold | Action |
|---|---|---|
| **Broken cross-links** | Any `[text](path)` where path doesn't exist | Flag for repair |
| **Stale code examples** | Code using deprecated APIs or old syntax | Flag for update |
| **Missing truth labels** | Speculative claims without *[Speculative]* marker | Flag for labeling |
| **Short docs** | Under 300 words | Flag for expansion |
| **Missing Further Reading** | Doc has no Further Reading section | Add section automatically |
| **New related docs not cross-linked** | A doc exists that should be linked | Auto-add cross-link PR |

```yaml
# .github/workflows/doc-refresh.yml
name: P011 Documentation Nightly Refresh

on:
  schedule:
    - cron: '0 2 * * *'  # 2am UTC nightly
  workflow_dispatch:

jobs:
  doc-refresh:
    runs-on: ubuntu-22.04
    steps:
      - uses: actions/checkout@v4

      - name: Run documentation health check
        run: |
          python3 scripts/doc_health_check.py \
            --docs-dir docs/ \
            --min-words 300 \
            --report /tmp/doc-health-report.json

      - name: Publish report to Hermes
        run: |
          curl -sf -X POST "${{ secrets.HERMES_URL }}/events" \
            -H "Content-Type: application/json" \
            -d "{
              \"event_type\": \"p11.doc.health_report\",
              \"payload\": $(cat /tmp/doc-health-report.json)
            }"

      - name: Open issues for flagged docs
        if: always()
        run: |
          python3 scripts/create_doc_issues.py \
            --report /tmp/doc-health-report.json \
            --github-token ${{ secrets.GITHUB_TOKEN }} \
            --repo ${{ github.repository }}
```

| **Ebook chapter** | Fabric KB + build artifact + Claude | Generate chapter following 11-step P011 pattern | Markdown → PDF |

| **Quiz questions** | Chapter content | Generate 5 MCQ + 2 code challenges per chapter | JSON quiz format |
| **Slide deck** | Chapter summary | Extract key points; format as presentation | YAML → reveal.js |
